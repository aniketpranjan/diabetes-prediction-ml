# Dataset Directory

Contains the dataset: [`diabetes_prediction_dataset.csv`](file:///d:/diabetes-prediction-ml/data/diabetes_prediction_dataset.csv) (100,000 patient records).

### Features:
1. **`gender`**: Categorical (`Female`, `Male`, `Other`)
2. **`age`**: Patient age in years
3. **`hypertension`**: High blood pressure diagnosis (`0` = No, `1` = Yes)
4. **`heart_disease`**: Heart disease history (`0` = No, `1` = Yes)
5. **`smoking_history`**: Smoking category (`never`, `No Info`, `current`, `former`, `ever`, `not current`)
6. **`bmi`**: Body Mass Index (weight in kg / (height in m)²)
7. **`HbA1c_level`**: Hemoglobin A1c test (average blood sugar over 2–3 months)
8. **`blood_glucose_level`**: Blood glucose level (mg/dL)
9. **`diabetes`**: **Target Variable** (`0` = Non-Diabetic, `1` = Diabetic)
